# Michelle's Celebrity Lookalike Tracker

A lightweight single-page app to tag how many times Michelle gets told she looks or sounds like
Taylor Swift, Scarlett Johansson, or Miley Cyrus — including the location and optional notes.

## Run locally

Open `index.html` in your browser, or run a local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/index.html`.

## Use on iPhone

Open `index.html` in Safari, tap the Share icon, and choose **Add to Home Screen** to use the
tracker as a standalone app.

## Share a link with someone else

If you want a simple link to send, the easiest option is to host this folder with GitHub Pages:

1. Push this repository to GitHub.
2. In the repo settings, enable **Pages** and point it at the `main` branch (root).
3. Copy the published URL (it will look like `https://<username>.github.io/<repo>/index.html`).
4. Share that URL with your girlfriend and she can open it on her phone.
